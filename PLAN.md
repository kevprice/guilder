# Project status

## Implemented

- Main investigation, consent-based and mechanical release routes, and Rowan's final walk beyond the gate.
- Thirty in-house companion discoveries, personal records, character portraits and permanent homecomings.
- Varied opening jobs, explicit story/plot labels, regional campaigns and progressively demanding contracts.
- Quadratic XP growth, exclusive level choices, six class branches, skills, restoration and reanimation.
- Visible home defence, daily danger, room damage, injury stages, lethal adventures and conscious retreat.
- Shared equipment storage and individual ownership.
- Working workshop, garden and infirmary facilities, with salvage, supplies, workers, upgrades and reusable utility/decorative furnishings.
- Workshop batch orders and priority changes, automatic collection, safe refunds, crop reserve targets and preserved paused progress.
- Reclamation of spare stored equipment and furnishings, blueprint refits, exact item reservations and cancellation returns.
- Survey and salvage expeditions, facility blueprints, safe mid-journey decisions, repeat cooldowns and guardian trophies.
- Room overview and facility pages, shared furniture storage, worker stat forecasts and expedition preparation budgets.
- A sprawling tower and underworld with keys, traps, secret passages and distinct chambers.
- Room focus, zoom, themed interiors, personal decoration, visible weapons, magical effects and creature silhouettes.
- Independent saved character positions, individual character/training/diary pages and contextual object affordances.
- Versioned save compatibility and stored-copy migration.
- A single generated-reference pipeline, copy regression checks and consistent formatting.

## Planned extensions

These remain design work rather than current gameplay:

- Playable family-reunion destinations beyond the correspondence and farewell scenes.
- More conversations between companions and reactions to reanimation or class choices.
- Negotiated departure dates, off-site ally relationships and responses to repeatedly postponed farewells.
- Physical changes to the house as borrowed rooms are returned.
- More varied regional resolutions, including negotiation, relocation, testimony and vigils.

## Verification

Run `npm run check` for gameplay, save migration, progression, story reachability, copy and formatting checks. Regenerate references with `npm run docs` after changing character, discovery, diary or skill definitions. Browser checks cover discovery, room navigation, character switching, reports and close controls.
